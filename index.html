Connect your storage Advanced · optional

Your text and images already live in your GitHub repo — free, forever. There's nothing to set up here for normal writing. You only need this for video or large media: connect your own Cloudflare R2 bucket and clips upload straight to storage you own — no server in between, and nothing stored on anyone else's account.

  1. Create a free Cloudflare account, then an R2 bucket and an API token with Object Read & Write.
  2. Paste the endpoint, bucket name, keys and public URL into the fields below, then Save R2 keys.
  3. Add the bucket's CORS policy (the Show CORS policy button below) so your browser is allowed to upload.
Video storage — Cloudflare R2

Optional. Add your own Cloudflare R2 keys and the video block gains an Upload to R2 button — your phone uploads a clip straight to your bucket, no server in between. Keys are stored only in this browser, like your GitHub token. Create an R2 API token with Object Read & Write on the bucket.

Where the bucket serves objects publicly — your R2 custom domain, or the pub-…r2.dev URL. The video's src becomes <public base>/videos/….

Uploads go through a small Cloudflare Worker that writes to the same bucket via an R2 binding — it never touches <account>.r2.cloudflarestorage.com (which can fail a TLS handshake on some accounts). Deploy the Worker in cloudflare/r2-upload-worker, then paste its URL + secret here. Access key / secret above aren't needed on this path — but keep the Public base URL set.

The same Worker also powers free image generation (✦ Generate on any image block) via Cloudflare Workers AI (FLUX) — no AI key needed. Add the [ai] binding to the Worker's wrangler.toml and redeploy (npx wrangler deploy) to enable it.

Browser uploads need a CORS policy on the bucket. Paste this at Cloudflare → R2 → your bucket → Settings → CORS policy:

Note: this is a raw upload — no transcode (the clip is stored as-is). On a UK ISP/mobile network, R2 uploads can be blocked by SNI filtering — turn on a VPN/WARP if an upload fails to connect.
